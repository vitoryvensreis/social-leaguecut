Opção avançada: usar vídeo hospedado em URL HTTPS
Só use se o vídeo já estiver hospedado publicamente. Quando colar, o sistema utilizará este endereço.

Como funciona?

Você escolhe o vídeo, e o Social LeagueCut o envia para o servidor. No horário marcado, a Meta recebe e publica o Reel. O painel guarda o link e coleta as métricas disponíveis.

Para testar agora, escolha um horário próximo. A VPS precisa estar ativa.
Aplicável quando selecionar mais de uma conta.
Nenhuma postagem é criada antes de confirmar.
